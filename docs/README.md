## Quick Start

```bash
composer install
npm install
npm run build

# Watch mode
npm run start
```

See [DEVELOPER-GUIDE.md](DEVELOPER-GUIDE.md) for full setup.

### Booking shortcode

```
[nobat_booking]
[nobat_booking schedule_id="5"]
```
